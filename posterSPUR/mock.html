02

Signal, smoothing & peaks

EEG measures tiny oscillating electrical potentials (µV) generated by synchronised firing of cortical neurons beneath the scalp electrode. Convention splits this signal into five canonical frequency bands — δ θ α β γ — each linked to different arousal / cognitive states.

Why smooth before detecting peaks?

Like filtering a loud air-conditioner hum out of a singer's recording, we smooth each trace to strip noise and reveal the underlying rhythm — then detect peaks in that smoothed signal. Alpha traces with more, sharper peaks reflect stronger rhythmic synchronisation.

The smoothing model

y(t) = f(t) + ε   where   f(t) = Σⱼ₌₁ᵏ βⱼ · Bⱼ(t)

A generalised additive model (mgcv::gam) fits a smooth function f(t) as a weighted sum of basis functions Bⱼ. k = 70 sets the maximum number of basis functions — an upper limit on how flexible the curve is allowed to be. The fit is then penalised back down via cross-validation, so k=70 gives enough room to trace real oscillations without letting the curve chase sample-to-sample noise.

03

Methodology

Phase 1 — data collection & organisation
Resting-state EEG (32-channel cap, 128 Hz, eyes-open, 180 s fixation) was collected and structurally organised by Conor Thornberry as part of his PhD research, then band-pass filtered into δ θ α β γ and reshaped into a standard long format for this pipeline.
Phase 2 — feature engineering

Two families of features are computed: per-band (one band × channel × scaling at a time) and cross-band (combining bands within a channel).

Per-band

Time-domain

mean, skewness, kurtosis, q25, q75

Peak

num_peaks, peak_frequency, mean/max/sd peak amplitude, mean/sd inter-peak interval

Hjorth

activity, mobility, complexity activity = Var(x) mobility = √(Var(x′)/Var(x)) complexity = √(Var(x″)/Var(x′)) / mobility

Entropy

sample entropy — how predictable the next value is from the pattern so far; spectral entropy — how spread out (vs. peaked) the power spectrum is.

Power

absolute band power, mean power spectral density (PSD), peak PSD frequency

Cross-band

Relative power

each band's share of total power per channel (delta, theta, alpha, beta, gamma)

Power ratios

θ/α, α/β, δ/β, θ/β, and a stress index (α+θ)/β

Peak PSD (cross-band)

dominant frequency / band contributing the strongest peak in each channel's combined spectrum

Phase 3 — feature extraction

Core of the extraction function, run once per band × channel × scaling combination:

get_features_single <- function(x, time, scaling = "z_score", k = 70) { norm_x <- scale(x) # normalise fit <- gam(norm_x ~ s(time, k = k)) # GAM smooth smooth_x <- predict(fit, data.frame(time = time)) peaks <- findpeaks(smooth_x, minpeakheight = mean(smooth_x) + sd(smooth_x), minpeakdistance = 10) c(mean = mean(smooth_x), skewness = skewness(smooth_x), n_peaks = nrow(peaks), activity = hjorth(smooth_x)$activity, mobility = hjorth(smooth_x)$mobility, complexity = hjorth(smooth_x)$complexity, sample_entropy = sample_entropy(smooth_x), spectral_entropy = spectral_entropy(smooth_x)) }
Phase 4 — feature cleaning
NA analysis showed missingness was almost entirely peak-related (e.g. inter-peak interval is undefined when fewer than two peaks are detected in a trace). These channels/features were identified and removed, taking the matrix from 11,201 to 10,422 robust features — see the funnel in Results →.

05

Discussion & future direction

The 10,422 cleaned features are now ready for LASSO regression (L1 penalisation), which shrinks irrelevant feature weights to zero — a natural fit given far more features than participants — to identify which markers most reliably predict age while guarding against overfitting.

Selected markers could ultimately support clinical screening for cognitive decline, or inform the design of Brain–Computer Interfaces (BCIs).
